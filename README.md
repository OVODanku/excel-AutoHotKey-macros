# Excel AutoHotkey Macros 🚀
This repository contains personal AutoHotkey (AHK v2.0) scripts I use to improve productivity while analyzing RFQ bid sheets in Excel.

## ✨ Features

- Hold `Ctrl + Shift` + scroll mouse wheel ↑↓ → select rows with `Ctrl + Shift + ↑↓`
- Hold `Ctrl + Shift` + click mouse left/right → select columns with `Ctrl + Shift + ←→`
- Double-click mouse wheel → jump to top (`Ctrl + Home`)

## 📂 Files

- `Ctrl + Shift + mouse wheel.ahk` — scroll to navigate rows
- `Ctrl + Shift + click.ahk` — mouse left/right buttons to move columns
- `double_middle_click_scroll_top.ahk` — double-click middle button to jump to top
- `mouse_and_middle_click_top.ahk` — all functions in one file

## 🛠️ Requirements

- [AutoHotkey v2.0](https://www.autohotkey.com/v2/)
